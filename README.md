# 달빛 자장가

잠들기 전에 켜면 바로 자장가와 배경 소리가 나오는 웹 앱(PWA)입니다.
음악 파일 없이 브라우저가 직접 소리를 만들어서, 인터넷이 없어도 동작합니다.

## 기능
- **'잠들기 시작' 버튼으로 시작** (그림은 눌러도 시작되지 않아요): 자장가 55곡 + 배경 소리(빗소리 / 파도 / 벽난로 / 포근한 소음)
  - 저작권이 끝난 실제 곡 39곡: 크리스마스 캐럴 11곡, 동요·민요 12곡, 클래식 11곡, 옛 노래 5곡
  - 앱이 직접 만든 '달빛 오르골' 곡 16곡
- **여러 곡 반복 재생**: 원하는 곡을 여러 개 고르면 한 곡씩 1~2분 듣고 다음 곡으로 넘어가며 계속 반복 (순서대로 / 섞어서)
- **앱을 열면 바로 재생하기** (기본은 꺼짐): 켜두면 앱을 열자마자 재생해요
- **크리스마스 테마**: 11월 20일부터 1월 6일까지 눈 내리는 크리스마스 그림과 빨간 포인트로 바뀌어요
- **잠들기 타이머**: 15분 / 30분 / 1시간 / 끄지 않기. 끝나기 몇 분 전부터 소리가 서서히 작아져요
- **악기 고르기**: 피아노 / 오르골 / 칼림바
- **알람·전화가 오면 멈춤**: 알람이나 전화가 울리면 자장가가 완전히 멈춰서 알람 소리를 가리지 않아요
- **4-7-8 호흡 가이드**: 4초 들이쉬고, 7초 멈추고, 8초 내쉬기
- 20초 동안 화면을 안 만지면 화면이 더 어두워져요
- 마지막 설정을 기억해서 다음에 그대로 시작돼요

## 실행
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

## 휴대폰에 앱처럼 설치하기
GitHub Pages 같은 곳에 올린 뒤 휴대폰으로 접속해요.
- **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가"
- **안드로이드(Chrome)**: 메뉴 → "홈 화면에 추가" 또는 "앱 설치"

## 참고
- 아이폰 Safari는 웹페이지가 볼륨을 바꾸지 못해서 음량 조절과 페이드 효과가 동작하지 않아요. 휴대폰 볼륨 버튼으로 조절해 주세요. 타이머가 끝나면 소리는 정상적으로 꺼져요.
- 기존 곡은 모두 저작권이 끝난 곡이고, '달빛 오르골' 곡들은 앱이 직접 만든 곡입니다.

## 안드로이드 앱(APK)
`.github/workflows/android.yml`이 푸시할 때마다 APK를 자동으로 만들어서
[Releases의 apk-latest](../../releases/tag/apk-latest)에 올립니다.

- 휴대폰에서 `dalbit-lullaby.apk`를 받아 설치하면 돼요 ("출처를 알 수 없는 앱" 설치 허용 필요)
- 앱에서는 켜자마자 바로 재생되고, 화면이 꺼져도 알림 표시줄의 "달빛 자장가"가 소리와 타이머를 유지해요
- 직접 빌드하려면: `npm install && npm run sync` 후 `android/` 폴더를 Android Studio로 열기

## 그림
`assets/cat.webp`는 `art/paint-cat.html`, `assets/xmas.webp`는 `art/paint-xmas.html`(순록은 `art/paint-reindeer.html`)이 코드로 직접 그린 그림입니다. 앱 아이콘 원본은 `art/icon.svg`예요.
`node art/render.js`로 다시 그릴 수 있어요.
